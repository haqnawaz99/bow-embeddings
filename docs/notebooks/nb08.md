## What this notebook covers

Retrieval-Augmented Generation (RAG) connects the retrieval pipeline built in NB07 to a local language model. Retrieved passages are injected into a structured prompt, and the model generates a grounded, cited answer. You will also compare RAG answers against answers generated without any context.

## What the previous approach got wrong

FAISS retrieval returns a ranked list of passages. That is useful for a developer, but an end user asking a question wants a direct answer — not ten paragraphs to read through. A language model can synthesise the retrieved evidence into a coherent response.

## Key concept

**RAG pipeline**: three stages working together.

```
Query
  |
  v
[SBERT encoder] --> query vector
  |
  v
[FAISS IndexFlatIP] --> top-k passages
  |
  v
[Prompt builder] --> "Context: [4:36] ...\n\nQuestion: ..."
  |
  v
[flan-t5-small] --> grounded answer with citations
```

```python
# Build a grounded prompt
prompt = SYSTEM_PROMPT + "\n\n--- Context ---\n" + context
                       + "\n\n--- Question ---\n" + query
                       + "\n\n--- Answer ---\n"

# Generate
output = model.generate(**tokenizer(prompt, ...), max_new_tokens=96)
```

## Topics covered

- `encode_query_vec()` — standalone function, inspectable query vector
- `retrieve()` — returns ranked dicts with verse_id, text, score
- `build_rag_prompt()` — citation tags, per-passage truncation, context cap
- `SYSTEM_PROMPT` — grounding instruction, citation requirement, "cannot tell" fallback
- `google/flan-t5-small` — seq2seq generator, ~300 MB, CPU-friendly
- `USE_LOCAL_LLM` flag — run retrieval-only mode without downloading the model
- RAG vs no-context side-by-side comparison
- "What This Notebook Is NOT" — honest list of what the prototype omits

## Limitation this notebook reveals

The naive RAG pipeline has no re-ranking, no hybrid retrieval, no evaluation, and no faithfulness check. The retrieved passages may be off-topic, the model may ignore the context, and there is no way to measure whether the answers are correct.

All of these are fixed in NB09.
