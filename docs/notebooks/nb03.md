## The Word Order Problem

Both BoW and TF-IDF are completely order-blind. The sentences:

- "dog bites man"
- "man bites dog"

produce **identical representations** despite having very different meanings. And the famous negation problem:

- "not merciful" → after stopword removal → "merciful"
- "not wicked" → after stopword removal → "wicked"

Both become their opposite after stopwords are removed. Word order carries critical information that BoW and TF-IDF silently discard.

---

## What are N-Grams?

An **N-gram** is a contiguous sequence of N words treated as a single feature.

| N | Name | Example from "have mercy on the believers" |
|---|---|---|
| 1 | Unigram | "mercy", "believers" |
| 2 | Bigram | "have mercy", "mercy on", "on the", "the believers" |
| 3 | Trigram | "have mercy on", "mercy on the", "on the believers" |

The sliding window moves one word at a time across the text.

```
Text: "have mercy on the believers"

Bigrams (sliding window of 2):
  [have mercy] [mercy on] [on the] [the believers]
```

### When to use each N

| N-gram | Best for |
|---|---|
| Unigrams | General topics, bag-of-words tasks |
| Bigrams | Phrases, negation ("not good"), collocations ("day of judgement") |
| Trigrams | Fixed expressions, named entities |
| 4+ grams | Rarely useful — vocabulary explosion, data sparsity |

---

## The Stopword Trap with N-Grams

!!! warning "Critical Design Decision"
    If you remove stopwords **before** building n-grams, meaningful bigrams are destroyed:

    | Original | After stopword removal | Bigrams extracted |
    |---|---|---|
    | "not good at all" | "good" | only "good" — negation gone |
    | "day of judgement" | "day judgement" | "day judgement" — preposition gone |
    | "most merciful" | "merciful" | only "merciful" — qualifier gone |

    **Rule:** When using n-grams to capture phrases, either remove stopwords *after* building n-grams, or keep stopwords for n-gram features while still removing them for unigram features.

## N-Gram Vectorization

```python
from sklearn.feature_extraction.text import CountVectorizer

# Unigrams only
unigram_vec = CountVectorizer(ngram_range=(1, 1))

# Bigrams only
bigram_vec = CountVectorizer(ngram_range=(2, 2))

# Unigrams + bigrams together
combined_vec = CountVectorizer(ngram_range=(1, 2))
```

The `ngram_range=(min_n, max_n)` parameter controls which n-gram sizes are included as features.

## Bigram Language Models

An N-gram language model assigns a probability to a sequence of words. A **bigram language model** estimates:

```
P(word | previous word)
```

The **chain rule** says:
```
P(w1, w2, w3, w4) = P(w1) × P(w2|w1) × P(w3|w2) × P(w4|w3)
```

The **Markov assumption** simplifies this: only the immediately preceding word matters (not the full history). This is why it is called a bigram (2-word window) model.

**Training:** Count how often each word follows each other word, then normalize:
```
P(merciful | most) = count("most merciful") / count("most ___")
```

**Use cases:**
- Text generation (predict the next word)
- Spelling correction (which sequence is more likely?)
- Speech recognition (which word sequence fits the audio best?)

## Comparison: Unigram vs Bigram vs Trigram

For a query like "not merciful":

| Method | Behavior |
|---|---|
| Unigram | Finds verses with "merciful" — ignores "not" |
| Bigram | Finds verses with the exact phrase "not merciful" |
| Trigram | Finds verses with three-word sequences containing "not merciful" |

Bigrams and trigrams are more precise but require the exact phrase to appear in the document — they have lower recall than unigrams.

## Limitations

**1. Vocabulary explosion**
Bigrams of a 5,000-word vocabulary → up to 25 million possible bigrams. In practice most never occur, but dimensionality grows rapidly.

**2. Data sparsity**
Most bigrams appear only once or twice in the corpus — not enough data to estimate reliable statistics.

**3. Fixed window — no long-range dependencies**
A bigram model only looks one word back. "The man who the woman the child liked hated died" — a human understands the deep nesting, a bigram model is lost.

**4. Still no semantic understanding**
"have mercy" and "show compassion" are completely unrelated bigrams despite expressing the same idea.
